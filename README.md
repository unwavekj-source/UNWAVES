# CA UNWIND Festival

CA UNWIND – Phase 1 Website Creation Prompt

Project Overview

Design and develop the first version (MVP) of the official CA UNWIND website.

This is NOT a conference website, corporate dashboard, LMS, or admin portal.

CA UNWIND is a 15-day online festival for Chartered Accountancy students that begins after every CA attempt.

The website should feel like entering an online celebration where students participate in activities, complete challenges, vote, showcase creativity, earn achievements, and experience a memorable journey.

The first emotion a visitor should feel is:

"Wow... the event has started."

Not:

"I'm visiting a website."

The design philosophy should combine the excitement of an online festival, the engagement of a gamified experience, and the polish of a premium digital product.
